Rounded-full status pill or tier tag. Maps each brand accent to its semantic meaning, per the canonical color rules.

```jsx
<Badge tone="success">Resolved</Badge>
<Badge tone="attention" solid>Pending</Badge>
```

Tones: `success` (green), `info` (blue), `highlight` (pink), `attention` (orange), `warning`/`danger` (derived amber/red for aging alerts), `neutral`. `solid` fills with the tone color instead of the soft tint.
