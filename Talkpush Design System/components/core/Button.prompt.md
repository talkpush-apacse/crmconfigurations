The primary action control, taken from the Talkpush Sign component spec (default size h-12 px-6 py-3, rounded-md).

```jsx
<Button variant="cta" onClick={() => sign()}>Sign document</Button>
```

Variants: `default` (near-black), `cta` (pink, primary call to action), `accent` (orange), `sage` (green), `destructive`, `secondary`, `outline`, `ghost`, `link`. Sizes: `sm`, `default`, `lg`. Reserve `cta` for the one primary action per screen.
